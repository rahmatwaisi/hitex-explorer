# HITEX Explorer

Browse HITEX startups, exhibitors, sponsors, media, speakers and agenda.

```bash
pnpm install
pnpm dev
```

Took part in HITEX? Complete your startup's profile with the [startup form](https://hitex2026.netlify.app/contribution/form),
or your sponsor profile with the [sponsor form](https://hitex2026.netlify.app/contribution/sponsor/form). See [CONTRIBUTING.md](CONTRIBUTING.md).
